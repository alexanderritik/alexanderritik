## Open Source Projects

- 🧪 **[BYOT — Bring Your Own Tests](https://github.com/alexanderritik/BYOT)** `Go · Docker · PostgreSQL · MinIO`  
  Production monitoring that runs your existing Playwright/k6/custom test binaries on a schedule inside ephemeral containers. Catches what CI never sees — third-party outages, cert expiry, API drift. Self-hostable, `docker compose up` and done.

- 🕸️ **[ArchHelix](https://github.com/alexanderritik/ArchHelix)** `Go · TypeScript · React`  
  Drop any codebase in, get an interactive dependency graph out. Local Go backend + React UI. Originally cloud-hosted; rebuilt engine locally after hitting AWS costs. Ships as a single binary via `install.sh`.

- 🗄️ **[dbgraph](https://github.com/alexanderritik/dbgraph)** `Go · CLI`  
  Simulate schema changes before you apply them. Visualises cascading impact across tables, foreign keys, and indexes — on any database. Zero config, 10-second setup, MIT licensed.

- 📖 **[Central Swagger Repository](https://github.com/alexanderritik/Central-Swagger-Repository)** `HTML · CI/CD · OpenAPI`  
  Centralised hub for microservices API documentation — real-time sync across services, lightning-fast search, developer-first dark mode UI. Each microservice pushes its Swagger spec via CI/CD; one unified interface serves it all. [Live demo →](https://alexanderritik.github.io/Central-Swagger-Repository/)

- 📦 **Github2s.com** *(archived)* `Python · AWS · React · ReactFlow`  
  Real-time dependency graph across 10M+ GitHub repos with an integrated code editor. Hit 1,000+ users before AWS costs killed it. The core insight lives on in ArchHelix.
